# PRD Coverage

Core: Admin, Doctor, Patient portals; registration/login; appointments; medical records; prescriptions; billing; analytics.

Differentiators implemented: AI symptom triage, OpenAI-compatible streaming, Socket.IO doctor availability, appointment conflict prevention, prescription QR data, audit trail, bed/ward management, demo billing/payment state, no-show status support, REST API versioning, automated backend/frontend tests, GitHub Actions, Render/Vercel deployment manifests.

Stretch intentionally left outside the MVP: video consultation, multilingual portal, pharmacist portal, insurance workflow and predictive analytics. They can be added without replacing the core modules.
